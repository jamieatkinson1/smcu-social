# SMCU Image Library — Operations

## Upload and copy a public URL

1. Sign in through Cloudflare Access as Jamie.
2. Open **Images**.
3. Drop a PNG, JPEG or WebP image onto **Upload image**, or choose **Select images**.
4. Wait for the upload progress and success message.
5. Preview the stored image.
6. Select **Copy URL**.

The copied URL is permanent and publicly retrievable without authentication.

## Replace an image

Select **Replace**, choose the new image and confirm. Replacement keeps the established public URL. If the image has recorded publication usage, the Library requires an additional warning confirmation.

## Delete an image

Select **Delete** and confirm. Deletion is unavailable for permanent legacy images. Images with recorded usage require an additional warning confirmation.

## Supported files

PNG, JPEG and WebP files up to 10 MB are accepted. Empty, corrupt, mismatched, unsupported and duplicate files are rejected safely.
